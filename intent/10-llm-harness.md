# Intent 10: LLM-озвучка (сторона двойника — стенд сверки)

Автор: агент по общему слову Стана 2026-10-27 («сделай все модули за меня … не спрашивай ничего»). Статус: заявка принята Станом общим словом 2026-10-27.
Источник: docs/10-llm.md; docs/09-feedback.md; spec 09-chronicle-summary.

## Что и зачем
LLM только озвучивает уже принятое решение и ничего не пишет в мир. Двойник может проверить именно это: собрать из состояния «промпт» (структурированный список фактов) и сверить любую озвучку с журналом. Это тот самый критерий готовности из docs/10: «сказанное совпадает с логом».

## Что в документах уже есть
Контракт и граница в docs/10: ни одного SetValue из ответа модели; фолбэк на модуль 09 обязателен; промпт собирается из Global'ов реестра и Role/Trait/Status NPC.

## Что нужно создать (в двойнике; реализуемость в CK не проверена)
twin/voice.py: сборщик фактов из мира (чистая функция), детерминированный «озвучиватель-заглушка» на шаблонах 09, сверщик утверждений с журналом. Внешней модели и сети в двойнике нет.

## Не входит
Любой вызов реальной LLM; мост (sfse_http, AISS); TTS; память об игроке; сцена; запись в мир из озвучки (запрещена).

## Для спецификации
Перечитать docs 10, 09; spec 09-chronicle-summary. Моды: AISS, Eve Combat AI, sfse_http.
