# Intent 00: двойник v0 с нуля + набор «штопор» как первый приёмочный гейт

Автор: Стан. Статус: утверждён 2026-10-25 (v2, заменяет intent-shtopor-DS1-DS6 v1).
Источники: 11 S2d/S2e, 13 (ревизия enRAGE), 06 S1–S2/S4, 04 S1, 03 (вёдра), CHANGELOG-ревизия-enRAGE.

## Проблема
Прежний двойник потерян: в GitHub его нет, где лежит локально — неизвестно. Все калибровки (03 S5, 13 S3, 18, 06, 07) стоят, потому что их не на чём прогонять.
Восстанавливать старый смысла нет: он считал по формуле потерь, которую ревизия enRAGE признала дефектной.

## Ожидаемый результат
- Двойник v0, собранный с нуля по текущим документам, в постоянном хранилище (не в одноразовой среде).
- Три сценария «штопор» работают как приёмочный набор: DS1 (серия поражений), DS2 (голод + потеря узла), DS4 (большой против малого).
- Набор доказывает свою силу: возврат старой формулы потерь 13 валит DS1 и DS4; снятие потолка дезертирства валит DS2. Если не валит — набор не принимается.
- Журнал событий в формате 11 S2d: tick, phase, module, target, old, new, reason_code.
- Отчёт по прогону на одной странице, читаемый без чтения кода.
