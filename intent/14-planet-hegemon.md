# Intent 14: хозяин планеты (агрегированный контроль)

Автор: агент по общему слову Стана 2026-10-27 («сделай все модули за меня … не спрашивай ничего»). Статус: заявка принята Станом общим словом 2026-10-27.
Источник: docs/14-planet-owner.md; docs/15-planet-regions.md; docs/07 (гистерезис); docs/09 (сводка).

## Что и зачем
Один вопрос: есть ли смысл в сумме локальных исходов. Игрок может отбить каждую площадку отдельно, но у мира нет статуса «и что это значит для планеты». Хозяин планеты — единственный читаемый итог.

## Что в документах уже есть
Кандидат = у кого больше всех активов с запасом не меньше 1; гистерезис и cooldown 5–7 суток; третье состояние Contested (−1); хранимый Global `TF_PlanetHegemon`; MVP только легибельность: строка в сводке (docs/14).

## Что нужно создать (в двойнике; реализуемость в CK не проверена)
1. Статус хозяина с памятью (имя фракции или «Contested»).
2. Cooldown и запас как параметры.
3. Событие hegemon_change для 09.
4. Множитель RegionRecovery и метка на карте не вводятся (в двойнике нет RegionRecovery; метка — UI, не проверена).

## Не входит
Бонусы хозяина; визуальная метка; влияние на 08 (опционально по docs/14).

## Для спецификации
Перечитать docs 14, 15, 07. Моды: контроль систем и «хозяин региона» в Starfield, Sim Settlements Conqueror.
