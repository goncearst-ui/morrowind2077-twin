# Intent 03: масштаб экономики, налёт на объект, регионы — v2

Автор: Стан. Статус: решения приняты 2026-10-25, заявка разрезана на 03a/03b/03c/03d/04 (см. «Решения по открытым вопросам»). Это зонтичная заявка — в работу идут части.
Источник: отчёт 01; 06, 03, 13, 15, 17; ответы Стана по вопросам 1–3; разбор enRAGE и похожих систем (ниже).

## Проблема (без изменений)
Экономика 06 рассчитана на 5–10 чел., ростер 03 — на 100–300. В двойнике любая фракция тает от голода до единиц (DS1 40 → 13, DS4 90 → 30, RG1 30 → 1). Один регион не выдерживает двух Хищников. Добыча налёта не зависит ни от цели, ни от исхода боя.

## Решения Стана (2026-10-25)
1. **Еда: 3 порции на человека в сутки** (по числу приёмов пищи). Ставка 8 → 3.
2. **Оплата людей разного ранга должна быть разной** — открыта, нужно обсудить отдельно (см. «Открытые вопросы»).
3. **Добыча налёта = запас атакованного объекта × исход атаки × мораль группы.**
   - Объект без защиты, атакующие целы — берут, сколько унесут.
   - Есть раненые и убитые — решает мораль: высокоморальные спасают раненых и забирают тела вместо добычи; низкоморальные вычищают запасы, бросая своих.
4. **Регион = большая локация Starfield.** Все фракции — в одном родном регионе; их представители — в общем регионе.
5. **После нападения ресурсы объекта перемещаются в другие места** (идея из enRAGE).

| | Ставка 8 (сейчас) | Ставка 3 |

| Перевал кормит (доход 90, база 40) | ~6 чел. | ~16 чел. (Хищники ~13) |

## Решения по открытым вопросам (Стан, 2026-10-25)
0. Каждая фракция живёт в своём родном регионе (2–4 объекта). Представители всех фракций — в одном общем нейтральном регионе.
1. Оплата: доля добычи по ярусам (рядовой / ветеран / офицер) в симуляции + снаряжение по ярусу как видимый слой. Кредитов внутри фракции нет — принцип 06 сохраняется.
2. Брошенный раненый низкоморальной группы попадает в плен к обороне; судьба — по укладу победителя (таблица 13). Если обороны на объекте не осталось — погибает.
3. Представители в общем регионе: слухи (канал 09) + дипломатические инциденты (вход в матрицу 08). Торговля между фракциями — отложена, отдельной заявкой.
4. После удара: доля запаса уничтожается (как DepotLossRate 0.3 в 06), остаток переезжает на ближайший свой укомплектованный объект. У фракции с одним объектом — в тайник в соседнем поселении.
