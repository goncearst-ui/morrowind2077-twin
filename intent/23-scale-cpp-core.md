# Intent 23: масштаб «до 1000 планет» и ядро на C++

Автор: агент по словам Стана 2026-10-28; все решения ниже приняты Станом в переписке 2026-10-28. Статус: заявка принята Станом. Spec (specs/23-scale.spec.md) и plan (plans/23-scale.plan.md) для части «в двойнике» подготовлены 2026-10-28 и ждут утверждения Стана; C++-ядро и плагин не входят и ждут спайков 1–3. Код и tests/ не менялись.
Источник: Project «Morrowind 2077», документ claude/idea-interplanetary-scale.md (источник истины; здесь только выжимка); документ 11 (раздел «Решение Стана 2026-10-28»); CLAUDE.md.

## Что и зачем
Стан хочет расширить мод с уровня «локация, район, планета» до межпланетного: до ~1000 существующих планет, станции фракций с вожаками, корабли, стычки и штурмы, торговля, характер лидера на всех уровнях. Расчёт выносится из Papyrus в собственный SFSE-плагин на C++ (Steam-версия игры). Двойник на Python остаётся эталоном правил; C++-ядро сверяется с ним побитово по снимкам.

## Решения Стана (2026-10-28)
1. Планеты: существующие, до ~1000 (число от Стана, по данным игры не проверено); новых нет.
2. Все вычисления в плагине; Papyrus только клей (результаты диалогов, стадии квестов, вызов функций плагина).
3. Порядок: двойник (эталон) → C++-ядро как библиотека без привязки к игре, побитовая сверка по снимкам → тонкий слой плагина (Windows, HP OMEN).
4. Источник истины состояния: структуры плагина; Global'ы только зеркала для условий CK. Запасной вариант на Global'ах, если спайк сохранения провалится.
5. NPC: тысячи расчётных; именных сотни (вместо 5–10); рядовые остаются в вёдрах ростера.
6. Именные для старта: авторский ActorBase на каждого, фиксированный список заранее; продвижение из вёдер по событию отложено на позже.
7. Журнал двухуровневый: подробный (строка на изменение) для именных и спорных событий; сводный для остального.
8. «Тихие» планеты и системы считаются реже и сводно; период — параметр двойника, подбирается по прогонам; правило перехода тихая↔активная нужно задать в спецификации.
9. Побитовая сверка C++ с двойником идёт на уменьшенных мирах; стартовый эталон: 4 фракции, до 20 планет, до 100 именных, 1000 тиков. Полный масштаб проверяется инвариантами ядра.
10. Версия игры в Steam заморожена на дату старта, автообновление выключено, плагин обновляется по явному решению.
11. Лицензия мода GPL-3.0, исходники открыты.

## Что нужно создать (реализуемость в игре не проверена)
В двойнике: параметры масштаба в twin/params.py; уменьшенные эталонные миры; двухуровневый журнал; правило «тихая планета» с периодом; рост числа именных до сотен (по модулям 01/03/18). Вне двойника: C++-ядро, формат снимка, слой плагина, спайки. Расклад дня по месту, лидер как явный вход на всех уровнях, абордаж как способ перехода актива: всё [предл.], формулы не заданы, калибруются на двойнике первыми.

## Не входит
Код плагина и работа в Creation Kit; новые планеты; вывод LLM в мир; смена значений флагов по умолчанию.

## Что не решено
Спайки (категория C): сохранение состояния плагина вместе с сейвом; запись Global'ов из плагина; хук на прибытие в систему и на орбиту; чтение нашего состояния деревьями PCM и Cell Load Request; атака и абордаж NPC-кораблей скриптом; перенос именного NPC по результату тика; число адресуемых планет по данным игры; текст лицензии SFSE; версия игры, которую поддерживает libxse/commonlibsf. Правила «спорного события» для подробного уровня журнала. Правило перехода «тихая планета → активная».
