# 19 — Допрос: пленный как источник знания

*Новый модуль. Источник: ревизия «enRAGE» (2026-10-19). Зависит от: 01 (ярлык темперамента, `Fear` именных), 03 (ростер — кто пленный), 06 (склад), 09 (слой знания, единственный писатель флагов), 02 (свидетели казни), 04 (паранойя/чистка как вход). От него зависят: никто — модуль листовой.*

*Статус: **отложен до прохождения G6.** Контракт и правила объявлены сейчас, чтобы реестр и API 06/09 учли его до заморозки. CK-работы до G6 — ноль.*

*Статус по движку: **механизма допроса в Starfield нет; модуль целиком строится.** Ниже каждый кирпич помечен категорией A/B/C.*

---

## Зачем модуль

В проекте есть знание как механика (09, канал 6): клан не знает про ресурс, игрок не знает, где склад (06). Но у игрока нет **активного** способа знание добыть — только найти журнал квартирмейстера или услышать слух. Допрос закрывает эту дыру и замыкает петлю, которую ревизия enRAGE открыла в 06:

```
взять пленного → узнать, где склад → ударить по складу → штурм врага отложен (13)
```

Это ненасильственный (или не только насильственный) путь вмешательства в войну фракций — ровно то, что в enRAGE работает как «разговори человека, пока он не выдаст, где прячут деньги».

Готового мода с допросом пленного под Bethesda-игры (Skyrim/FO4/Starfield) в проверенных источниках **не найдено**. Модуль проектируется с нуля, отсюда отсрочка.

## Контракт

**Читает:** keyword'ы пленного (ярлык темперамента, 01), `TF_<Имя>_Fear`/`Loyalty` (только если пленный именной), `TF_Morale` его фракции, `TF_DepotSite` (06), `TF_Objective` (16), `TF_PendingArch` (07)
**Пишет:** **ничего в реестр.** Только локальное состояние сцены допроса (переменные квеста, не Global'ы) и вызовы чужих API
**Вызывает:** `Knowledge.Reveal(DEPOT)` (09); `Roster.RemoveMany(1, RELEASED_DESERTED)` (03); `Shock.AddPersonnel(1, вес)` (04) при казни; репутационное событие 02 при казни при свидетелях
**Фаза тика:** не участвует. Полностью событийный.

**Почему модуль ничего не пишет сам.** Всё, что допрос меняет в мире, уже имеет владельца: знание — 09, люди — 03, шок — 04, репутация — 02. Новый Global был бы вторым писателем чужой сущности.

## Механика

### 1. Взять пленного

| Шаг | Как | Категория |
|---|---|---|
| вывести из боя без убийства | ЭМ-оружие → бессознательное состояние (прецедент *Functional Brigs*) | **B** — поведение ЭМ подтверждено модом, но наш скрипт поверх не проверен |
| признать актёра пленным | `IsUnconscious()` на событии + опция активации «допросить» | **C** — функция из вики сообщества, крючок активации на бессознательном актёре не сверен |
| где идёт допрос | на месте, без переноса в карцер (вторая очередь — карцер по образцу *Functional Brigs*) | — |

**Только рядовые уровня B (persistent) и именные.** Рядовой уровня A существует в сцене как загруженный актёр, но у него нет persistent-ссылки — после допроса его судьба должна попасть в ростер, иначе отпущенный «вернётся» при следующем сбросе ячейки. Связь «загруженный актёр → строка ростера» — та же, что в 03 S4.

### 2. Страх — выводится, не хранится

```
СтрахДопроса = БазаПоЯрлыку(темперамент)
             + Давление × ШагДавления          ; локальный счётчик сцены, не Global
             + (100 − TF_Morale) × MoraleK      ; деморализованная фракция — разговорчивее
             [+ TF_<Имя>_Fear, если пленный именной]
```

`Давление` — сколько раз игрок в этой сцене пригрозил, ударил, выстрелил рядом (реплики диалога; enRAGE добавляет «дать посмотреть, как гибнут друзья» — у нас это требует сцены с несколькими пленными, вторая очередь). Счётчик живёт в переменной квеста и обнуляется по завершении сцены — **личной тикающей переменной у рядового не появляется** (правило 01).

| Темперамент (01) | `БазаПоЯрлыку` | Поведение |
|---|---|---|
| Пугливый | 50 | ломается быстро, говорит правду |
| Вспыльчивый | 20 | огрызается; при среднем страхе врёт, при высоком — говорит правду |
| Бродяга | 30 | говорит правду **за плату** (кредиты игрока), без давления |
| Хладнокровный | 10 | молчит; при высоком страхе — **ложь-ловушка** |
| Упёртый | 0 | молчит всегда, кроме случая `TF_Morale` фракции < 20 |
| без ярлыка | 30 | правда при пороге |

### 3. Что можно узнать — один крупный секрет

Пленный выдаёт **один** крупный секрет (у enRAGE — один-два; у нас один, потому что каждый секрет — это вызов чужого API, и их меньше). Меню вопросов авторское, ответы читают уже существующие Global'ы:

| Вопрос | Ответ берётся из | Эффект | Категория |
|---|---|---|---|
| где склад | `TF_DepotSite` (06) | `Knowledge.Reveal(DEPOT)` (09) | A для логики, B для реплик (по реплике на площадку, ≤ 3) |
| чего хочет вожак | `TF_Objective`, `TF_ObjStage` (16) | только речь; знание не хранится | A |
| что фракция собирается сделать | `TF_PendingArch` (07), активная ветка 04 | только речь — окно предсказания (09, работа 3) | A |

Секреты, которых **нет** в меню: где вожак сейчас, его распорядок (01, «отложено»), численность (это `Manpower` — игрок видит её в кадре, 12), расположение каждого поста.

### 4. Правда, ложь и ловушка — детерминированно

Без генератора случайных чисел (§13.2). Исход — функция (`СтрахДопроса`, темперамент):

```
СтрахДопроса < ПорогРазговора (60)         → молчит
иначе по таблице темперамента:              → правда | ложь | ложь-ловушка
```

- **Правда** — вызывает `Knowledge.Reveal`.
- **Ложь** — реплика называет другую площадку; `Knowledge.Reveal` **не вызывается**, флаг знания не ставится. Игрок узнаёт, что его обманули, придя на место.
- **Ложь-ловушка** — как ложь, плюс на названной площадке включается засада (enable-parent с 3–4 бойцами его фракции, взятыми **из ростера** — их гибель идёт через 03 как обычно). **Категория B:** засада расставляется руками на каждой площадке-кандидате один раз; потолок 3 площадки.

Ловушка — главный сюжет модуля: игрок, который давил на хладнокровного, получает не информацию, а последствие. И это читается — потому что ярлык «хладнокровный» звучал в репликах раньше (01, 09).

### 5. После допроса

| Решение игрока | Эффект | Через кого |
|---|---|---|
| **отпустить напуганного** (`СтрахДопроса` ≥ 60) | уходит из фракции: `Roster.RemoveMany(1, RELEASED_DESERTED)` | 03 |
| **отпустить ненапуганного** | возвращается во фракцию; если именной — `Loyalty` не меняется, память об игроке (02) сохраняется; **вход в ветку «паранойя/чистка» 04** — вернувшегося из плена подозревают | 04 (флаг шока) |
| **сдать охране** | по образцу *Functional Brigs*; для ростера — `RemoveMany(1, CAPTURED)` в ведро `Captured` | 03; **сдача охране — C**, механизм мода не наш |
| **казнить** | `Shock.AddPersonnel(1, 1.0)`; если были свидетели и игрок опознан — событие репутации (02) | 04, 02 |

**Чего нет — и почему.** У enRAGE отпущенный может увести с собой родственника или друга; у нас родственных связей в ростере нет, и вводить их ради одной ветки запрещено правилом «ключ заводится под потребителя». Сделки «за долг/клятву» у enRAGE — у нас частично уже есть как `Debt` именных (01); для рядовых — нет.

## Легибельность — три вопроса из 00

1. **Заметность.** Да: склад на месте или нет; засада или пустая площадка; человек исчез из лагеря (отпущен и ушёл).
2. **Атрибуция.** Да, полная — игрок сам вёл допрос.
3. **Дешевле вывести?** Не применимо: модуль ничего не хранит, он только вызывает чужие API.

Правило следа (09) соблюдается автоматически: каждое последствие допроса имеет след (склад, засада, пустая койка).

## MVP модуля (после G6)

**Что входит:** взять в плен одного рядового уровня B через ЭМ-оглушение; диалог с тремя вопросами; `СтрахДопроса` по ярлыку и давлению; исходы «молчит / правда / ложь» (без ловушки); два решения после — «отпустить» и «казнить».

**Критерий готовности:** (1) пугливый под давлением выдаёт склад, и `TF_DepotKnown` ставится; (2) упёртый не выдаёт ничего при любом давлении, пока мораль его фракции выше 20; (3) отпущенный напуганный исчезает из ростера и из лагеря и не возвращается после сброса ячейки; (4) ни одного Global'а модуль не пишет — G4 по логу чистый.

**Оценка:** ~12 ч, из них ~3 — двойник (таблица исходов, закон сохранения людей с ветками RELEASED/CAPTURED), ~9 — CK (захват, диалог, реплики на площадки).

## Стадии

**S0 — Двойник.** Таблица исходов, `СтрахДопроса`, ветки после допроса как события ростера. Проверка: закон сохранения людей не нарушается; ни один исход не зависит от случайности.

**S1 — Спайк захвата.** ЭМ-оглушение → `IsUnconscious()` → опция активации. По образцу *Functional Brigs*. Проверка: оглушённый актёр не умирает, с ним можно начать диалог. **Блокирует всё остальное.**

**S2 — Диалог и страх.** Три вопроса, давление репликами, порог разговора. Проверка: два пленных с разными ярлыками при одинаковом давлении ведут себя по-разному.

**S3 — Правда и ложь.** `Knowledge.Reveal` только на правде. Проверка: ложь не ставит флаг знания.

**S4 — После допроса.** Отпустить / казнить через 03/04/02. Проверка: отпущенный и казнённый корректно уходят из ростера разными `reason_code`.

**S5 — Ловушка.** Засада на площадках-кандидатах. Категория B. Проверка: засада формируется из живых людей ростера и их гибель учитывается.

**S6 — Карцер и сдача охране.** Вторая очередь, по образцу *Functional Brigs*. Требует проверки совместимости с этим модом, если он установлен у игрока.

## Риски

| Что | Риск | План Б |
|---|---|---|
| **Захват не работает** | ЭМ-оглушение или диалог с бессознательным актёром недоступны нашему скрипту | план Б — «сдача» через порог здоровья и `AllowBleedoutDialogue` (C); план В — допрос только именных через обычный диалог после угрозы (01, `Fear`) |
| Допрос как всезнание | игрок допрашивает каждого и знает всё | один крупный секрет на пленного; секретов в меню три; склад переезжает после удара (06) |
| Ловушка читается как баг | игрок не понял, что его обманули | ярлык «хладнокровный» звучит в репликах заранее; после засады — реплика атрибуции у выжившего |
| Пленный уровня A «воскресает» | отпущенный/казнённый рядовой без persistent-ссылки возвращается при сбросе ячейки | допрос только уровня B и именных; связь со строкой ростера обязательна (03 S4) |
| Конфликт с *Functional Brigs* | оба мода вешают опцию на оглушённого | S6 только после проверки совместимости; наш S1 не использует их карцер |
| Расползание меню | «а ещё где вожак, а ещё пароли» | меню — три вопроса до результата G6; новые — только с потребителем и следом |
| Казнь без последствий | игрок казнит всех, и ничего не происходит | шок 04 и репутация 02 при опознании — уже существующие последствия |

## Что модуль сознательно не делает

Пытки как отдельная механика (давление — реплики, без анимаций и без урона-системы); родственные связи пленного; хранимая память рядовых о допросе; новые Global'ы; допрос рядовых уровня A; случайность в исходах.
