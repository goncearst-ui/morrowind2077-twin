# 10 — LLM-озвучка

*Источник: §10, §15.6. Отдельный трек. Не блокирует ничего и ничем не блокируется, кроме наличия состояния для чтения.*

---

## Контракт

**Читает:** весь реестр ядра + Role/Trait/Status конкретного NPC
**Пишет:** ничего. **Категорически ничего.**
**Фаза тика:** не участвует

---

## Граница — единственное, что нельзя нарушить

**Детерминированный Papyrus решает. LLM только озвучивает уже принятое решение.**

LLM ненадёжна как источник истины для логики: галлюцинации, задержка, стоимость API. Не давать права менять состояние мира напрямую — ни одного `SetValue` из ответа модели.

Это не осторожность, а условие совместимости: если LLM пишет в состояние, вся конструкция модулей 04–08 перестаёт быть проверяемой на стенде.

---

## Как это работает технически

Papyrus не умеет в HTTP нативно. Обход: Papyrus пишет события через SFSE-хуки → внешний сервер читает → дёргает LLM API → ответ возвращается.

**Мост можно не строить с нуля.** Для Starfield он уже существует:

| Мод | Что даёт |
|---|---|
| **AISS — AI Settled Systems** | прямой аналог Mantella для Starfield: LLM-диалоги с памятью, personality-профилями, awareness квестов и состояния мира |
| **Eve AI** | локальная LLM (Qwen3 через llama.cpp, офлайн на GPU) управляет тактикой отрядов; у фракций уже есть поведенческие профили — практически готовый `LeaderAggression`, только в бою |
| **`sfse_http`** | отдельный открытый SFSE-плагин, HTTP прямо из Papyrus. Готовый кирпич моста, снимает большую часть работы |

*Mantella поддерживает только Skyrim и Fallout 4 — на неё не опираться.*

**Антипаттерн:** у Eve AI есть «World Director», процедурно собирающий точки интереса на планетах. Прямая противоположность §1. Не заимствовать, держать в уме только как пример того, чего не делать.

---

## Почему концептуально подходит

Все Global'ы реестра — **готовый system prompt**:

```
фракция сейчас: Контролёры ресурса; R=62 P=41 C=78 M=29
NPC: Role_Quartermaster, Neuroticism_High, Fear=34, помнит игрока (убил Дрейка)
```

Модель не заменяет систему, а озвучивает её состояние человеческим языком. Архетип — идеальное поле для промпта: одно слово задаёт весь тон.

---

## Отношение к модулю 09

Не конкуренты. **Модуль 09 — фолбэк, модуль 10 — апгрейд поверх него.**

Детерминированный чатер работает всегда и не зависит от внешнего сервера. LLM заменяет шаблонные реплики на генерируемые, читая **те же самые пороги и тот же `pendingArch`**.

Практическое следствие: работа над модулем 09 не пропадает при переходе к 10. Условия переиспользуются как есть, меняется только источник текста.

---

## MVP модуля

**Что входит:** один NPC; `sfse_http` поднят; system prompt собирается из четырёх Global'ов; одна реплика на запрос, без TTS, без памяти.

**Критерий готовности:** NPC своими словами говорит о состоянии фракции, и сказанное совпадает с логом. Расхождение = LLM галлюцинирует, и это ловится сразу.

**Оценка:** ~12 ч, из которых большая часть — возня с мостом, а не с промптом.

---

## Стадии

**S1 — Мост.** `sfse_http`, запрос-ответ на заглушке. Проверка: работает без сети внешнего API (локальная модель) — иначе мод зависит от чужого сервиса.
**S2 — Prompt из состояния.** Сборка контекста из реестра. Проверка: сказанное сверяется с логом тика.
**S3 — Персона NPC.** Role/Trait/Status в промпт. Проверка: два NPC с разными трейтами в одной ситуации звучат по-разному.
**S4 — Память об игроке.** Персональная репутация из модуля 02 в контекст.
**S5 — Фолбэк.** Мост недоступен → молча откат к шаблонам модуля 09. Проверка: игрок не должен видеть ошибку.
**S6 — TTS.** Дороже всего, эффект наибольший. Последним.

## Риски

| Что | Риск | План Б |
|---|---|---|
| Внешняя зависимость | мод перестаёт работать без сервера/модели | S5 обязателен: фолбэк на модуль 09 не опционален |
| Галлюцинации | NPC говорит о том, чего в состоянии нет | промпт с явным запретом додумывать факты; сверка с логом на S2 |
| Порог входа для игрока | требует SFSE, плагин, локальную модель | распространять **отдельным опциональным аддоном**, не частью основного мода |
| Задержка | пауза перед репликой ломает темп | реплика только в диалоге, не в idle-чатере |
| Соблазн дать LLM права | «пусть сама решает» | архитектурный запрет: ни одного `SetValue` из ответа |
