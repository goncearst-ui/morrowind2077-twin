Единица времени: 1 тик = 1 сутки.


## 0. Коротко, человеческим языком
В нейтральном регионе («хаб») у каждой фракции есть свой представитель. Он делает две вещи. Во-первых, через него идут слухи: если с фракцией что-то случилось (убит вожак, удар по складу, штурм, смена хозяина планеты), через 3 суток это появляется на доске слухов хаба, но только если её представитель жив. Убил представителя — заглушил канал этой фракции. Во-вторых, его убийство или оскорбление — инцидент: если игрок подстроил, что это сделала другая фракция, пострадавший клан сильнее ненавидит подставленную (это рычаг «разжигание войны» из docs/08, +5, затухание −1 в 10 суток). Если игрок не в маске, подстава раскрыта: обычное убийство, репутация падает по 02.

Выключатель `envoys_enabled`, по умолчанию False; требует `reputation_enabled` (02), `player_levers_enabled`, `leader_enabled`.

## 1. Что входит
1. Представитель: именной с role «представитель», profile «Дипломат», в хабе (регион "hub" без объектов и экономики). Не входит в Manpower, не убивается автономно, к преемственности не относится. Создаётся для каждой фракции при `envoys_enabled`.
2. Доска слухов хаба `World.hub_board`: событие фракции F из списка {leader_killed, officer_killed, assault (по обоим участникам), depot_strike, hegemon_change, war_start, war_end} попадает на доску через `hub_rumor_delay` (3) тиков, только если представитель F жив на момент публикации. Строка журнала `hub.board.<ключ>` 0 → 1, module 03d, reason HUB_RUMOR. Доска пишет события, но не меняет состояние фракций (слух ≠ знание; знание 08c идёт своим путём).
3. Инцидент: убийство представителя игроком — `("kill", фракция, имя_представителя, {…})` проходит через 02 (свидетели, опознание); дополнительно событие `envoy_killed`.
4. Подстава `("frame", жертва, обвиняемый, {"masked": bool, "witnesses": int})`: убивает представителя жертвы; при masked True (по умолчанию) Relation(жертва → обвиняемый).i += `frame_h` (5.0) [док 08: разжигание войны +5], с общим потолком incite_cap (6.0) и затуханием 21d; при masked False подстава раскрыта: событие `frame_exposed`, H не меняется, остальное как при обычном убийстве по 02. Отказы: NO_ENVOY (представитель жертвы мёртв), SAME (жертва = обвиняемый), NO_FACTION.
5. Параметры в twin/params.py: `envoys_enabled` False, `hub_rumor_delay` 3, `frame_h` 5.0 [док 08], `hub_region` "hub".

## 3. Решения Стана и что осталось
Решения [Стан, 2026-10-25, intent 03d]: один общий нейтральный регион без экономики; представители — постоянные NPC; слухи — главный канал 09; убийство представителя — инцидент; торговля между фракциями не входит. Общее слово 2026-10-27: принять реализацию по рекомендации.
Допущения [предл]: в двойнике «виновная сторона» инцидента — игрок, а фракция-виновник возможна только как подстава (автономных убийств представителей нет); задержка доски 3 тика; +5 из docs/08 делится потолком 21d.

## 4. Что движок умеет на самом деле (A/B/C)
Двойник: события и числа. Для игры, по intent 03d и docs/15: постоянные NPC в общем регионе — B (расставляются руками в CK); реплики по состоянию фракции — условия диалога по Global (B); `SetEnemy`/`SetAlly` подтверждены в нативном Papyrus (аудит docs/08), `ModFactionReaction` нет. Представители больших фракций Starfield в хабе — только декорация (docs/15), их флаги не трогаем. Подстава как игровое действие (как игрок «подстраивает» убийство) в документах не описана — нужно создать; в двойнике это вход сценария.

## 5. Какие моды это уже делали
Проверено 2026-10-27 (чтение страниц и заголовков): мода Bethesda с нейтральным хабом, где представители фракций служат каналом слухов и одновременно целью для подставы, не нашёл. Starfield, Faction Warfare (Starfield Portal): игрок вмешивается в стычки; представителей и слухов нет. Docs/08 называет «разжигание войны игроком» (+5, −1 / 10 суток); прецедент механики в чужих модах docs не приводит. Вне Bethesda: Bannerlord, Diplomacy (Nexus 832): посланники и пакты, механики подставы там нет по странице. Поиск неполон.

## 6. Что не входит
Торговля между фракциями; реплики и сцена; несколько хабов; оскорбление как отдельное действие (только убийство); автономные убийства представителей.

## 7. Известные риски
1. Игрок может заглушить канал фракции, убив её представителя, и при этом заплатит репутацией по 02; баланс этого рычага проверяется на стенде 08f.
2. Подстава делит потолок H с подкупом (21d): сложить рычаги сверх 6.0 нельзя, это сознательно.
3. Доска не меняет знание фракций: если нужно, чтобы слух хаба открывал фракциям чужие объекты, это отдельная заявка (08c уже имеет свой слух).
