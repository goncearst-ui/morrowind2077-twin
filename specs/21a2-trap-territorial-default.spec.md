## 1. Что входит
1. Ловушка Дрейфующих [решение Стана: вариант (а)]. Правило 7 для фракции, которая сейчас Дрейфующие, срабатывает только если у неё есть объект в собственности (`owned`, не обязательно укомплектованный). Параметр `evo_drifter_needs_site` (True). Для остальных укладов правило 7 без изменений. Это правка docs/07 (правило 7), нужная в документе; запись в docs — только по слову Стана.
2. Территориальный шок [решение Стана: да]. Новое состояние `tshock` у фракции, только при `evolution_enabled`: +`evo_t_site` (25 = `shock_event_cap`) обороне за каждый потерянный объект (штурм, где победил атакующий; сдача актива), затухание `shock_decay_per_tick` (8) в сутки, события читаются на следующем тике. Ось P = `clamp(evo_p_scale × (shock + tshock))`. Масштаб остаётся 2.5 [предл]. По docs/04 P должна реагировать на оба шока «с сопоставимым весом»; вес территориального здесь равен личному.
3. Формула ΔM остаётся буквальной [решение Стана: «рост доли добычи поднимает мораль»]. Код не менялся; фиксируется критерием EV4/EV5 и этой строкой.
4. Включение по умолчанию [решение Стана: да]. `evolution_enabled` = True в `Params`. 17 из 70 прежних сценариев при включённой смене уклада краснеют по своим критериям (DS4, RG1, RG4, RG6, HD1, HD2, IC3, RP1, WS1, WS3, WE1 (ошибка индекса), RB1, RB2, RB4, RB5, SW1, SW2): они проверяют механику при неизменном укладе, критерии писал Стан. Менять критерии нельзя (CLAUDE.md). Поэтому `run()` по умолчанию прогоняет прежние 70 сценариев с `evolution_enabled` = False (как в 08e WR и WS закреплены старые числа войны); новые сценарии (EV…) и все будущие идут с включённой сменой уклада. Для прогона прежнего сценария со сменой передаётся `evo=True`. Что это значит для вас: по умолчанию в мире смена уклада включена; прежние учебные сценарии остаются на неизменном укладе, потому что их цели иные.

## 2. Приёмка (менять и ослаблять может только Стан)

## 3. Что движок умеет (A/B/C) и моды
Как в spec 21a §4–§5: арифметика двойника, о CK двойник ничего не утверждает; территориальный шок — новое состояние двойника (в игре нужно создавать, docs/04 описывает `TF_TerritorialShock`). Новой проверки модов к этой правке не требуется: механики те же.

## 4. Риски
1. Правило 7 с условием объекта может оставить безобъектных Дрейфующих навсегда: выхода вверх нет, пока не появится объект; он появится только через захват/освобождение объектов (13). Это следствие выбранного варианта (а); EV13 покажет, живы ли они.
2. Территориальный шок поднимает P при потере объекта: вход в Хищники станет чаще.
