Единица времени: 1 тик = 1 сутки.


## 0. Коротко, человеческим языком
К этому моменту у двойника около полутора десятков выключателей. Проверена каждая функция отдельно, но не все вместе. Строим один мир из четырёх фракций, включаем всё, гоним 1000 суток и проверяем то, что должно быть верно всегда: людей не прибавилось из воздуха, случайности нет, потолки целей и ключевых результатов не нарушены, у каждого изменения есть строка журнала. Итог — таблица «флаг → предлагаем включить по умолчанию / оставить опцией» для Стана; сами значения по умолчанию эта задача не трогает.

## 1. Что входит
1. Фабрика `everything(variant)`: четыре фракции (архетипы Контролёры, Хищники, Хранители, Дрейфующие; Колония-проект из 17), все флаги, существующие к моменту исполнения (список берётся из twin/params.py по шаблону `*_enabled`), включены; распорядок игрока из заготовленного сценария действий (kill, bribe, tip, persuade, capture, interrogate) [предл].
2. Инварианты, проверяемые на каждом тике: (а) сумма людей по фракциям + prisoners + captured + выбывшие = стартовая + приход по §1 docs/00 (прихода «из ниоткуда» нет); (б) каждая запись `log` имеет шесть полей; (в) на каждое изменение поля фракции есть строка журнала с тем же old/new; (г) активных целей не больше потолка 16a; (д) вызовов случайности нет.
3. Отчёт: таблица `reports/22-flag-table.md` — на каждый флаг: сколько строк журнала порождает за 1000 тиков, меняет ли итог относительно мира без флага (число расхождений), красные инварианты, рекомендация.
4. Перебор: каждый флаг по очереди выключается в мире «всё включено», и инварианты проверяются снова (n+1 прогонов).

## 2. Приёмка (чек-лист; менять и ослаблять может только Стан)
| # | Проверка | Обязано выполняться |
|---|---|---|
| IG1 | Инварианты | мир «всё включено», 1000 тиков: инварианты (а)–(д) выполняются на каждом тике |
| IG2 | Воспроизводимость | два прогона дают идентичные журналы |
| IG3 | Выключение по одному | при выключении любого одного флага инварианты всё ещё выполняются |
| IG4 | Все выключено | мир с выключенными флагами совпадает с эталоном сценария DS1 (журнал за 200 тиков) |
| IG5 | Живой мир | за 1000 тиков в мире «всё включено» происходит хотя бы одно событие каждого вида: штурм, война, смена уклада, смена вожака, достигнутая цель, допрос; вымерших фракций не больше одной |
| IG6 | Таблица | reports/22-flag-table.md создан, содержит строку на каждый флаг из params.py, а каждая рекомендация имеет числовое обоснование |
| IG7 | Журнал не пухнет | число строк журнала на 1000 тиков с флагами ≤ 20 × числа строк без флагов [предл]; превышение — красное и в отчёт |

Обратные проверки (R145+): тайный прирост людей → IG1; запись без журнала → IG1(в); флаг, пропущенный в таблице → IG6; случайный вызов → IG1(д); потолок целей снят → IG1(г). Каждая даёт красный.

## 3. Решения Стана и что осталось
Решения [Стан, общее слово 2026-10-27]: каждая функция за выключателем; значения по умолчанию меняются только отдельным решением Стана.
Допущения [предл]: четыре фракции; сценарий действий игрока; предел роста журнала 20×; рекомендация по флагам — моё предложение, не решение. Красные инварианты из-за ошибок прежних модулей идут в отчёт и в новые заявки, а не маскируются.

## 4. Что движок умеет на самом деле (A/B/C)
Двойник; Creation Kit не затрагивается. Для игры замечание: объём журнала и совместимость включённых слоёв в движке игры отдельно не оценивались; это сведение к одной таблице риска нагрузки — нужно создать оценку в CK отдельно.

## 5. Какие моды это уже делали
Проверено 2026-10-27: интеграционные стенды для симуляций фракций в модах Bethesda не нашёл (моды публикуют результат, а не стенд). Ближайший прецедент — собственные шорткаты проекта: 08f (мульти-фракционный стенд) и штопор DS. Поиск неполон.

## 6. Что не входит
Смена значений по умолчанию; баланс; сцена; CK.

## 7. Известные риски
1. Слои могут конфликтовать порядком фаз: первая красная строка IG1 может указывать на старый модуль, а не на новый.
2. 1000 тиков × n+1 прогонов — долго; допустимо.
3. Таблица рекомендаций может выглядеть решением: подписана «предложение», решает Стан.
