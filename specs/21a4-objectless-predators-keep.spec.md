# Spec 21a-4: Хищники без объектов не изгоняют людей, а продолжают контрабанду

Основа: reports/21a3-report.md, вопрос 1 (вариант (а)).
Статус: утверждён 2026-10-27 (Стан: «не изгонять людей из Хищников без объектов и вместо этого продолжать контрабанду»). Код не менять, пока у plan нет строки «Статус: утверждён».
Трек: только двойник. CK: ноль часов. Метки: [решение Стана], [предл].

## 1. Что входит
Параметр `predators_keep_without_site` (True) [решение Стана]. В решении при голоде (05, `decide`) фракция Хищники, у которой нет ни одного объекта в собственности, людей не изгоняет; контрабанда (06, `channels`) для неё идёт как раньше. Условие действует только при `evolution_enabled` (в мире со сменой уклада): прежние 70 сценариев идут с выключенной сменой и их решения при голоде не меняются. Это правка решения 05 (изгнание); запись в docs/05 — только по слову Стана.

## 3. Что движок умеет (A/B/C), моды
Как в spec 21a §4–§5: арифметика двойника; нового из движка не требуется.

## 4. Риск
Хищники без объектов больше не сокращают расход изгнанием: они держатся на контрабанде и дезертирстве. Возможна иная картина вымирания; измеряется EV13.
