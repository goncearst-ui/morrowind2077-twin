## 0. Коротко, человеческим языком
Игрок берёт пленного из фракции противника и задаёт ему один вопрос: «где склад». Исход зависит только от ярлыка темперамента, числа угроз и морали фракции: пугливый говорит правду, хладнокровный под давлением посылает в засаду, упёртый молчит. Правда ставит фракции игрока знание о складе (08c), ложь не ставит ничего, ловушка стоит бойцов. После допроса пленного отпускают (напуганный уходит из фракции, ненапуганный возвращается и вызывает подозрение), сдают или казнят. В игре эта часть откладывается до прохождения G6; здесь строится только арифметика.

Выключатель `interrogation_enabled`, по умолчанию False (требует `npc_state_enabled` из 01; `reputation_enabled` из 02 для свидетелей — желательно).

## 1. Что входит
1. Действие `{"do":"capture","target":F,"bucket":"skittish|ordinary|steady"}`: из ведра фракции F переводит одного человека в `prisoners` мира (запись: фракция, ведро/ярлык, давление 0); закон сохранения людей соблюдается (человек не пропадает из подсчёта). Действие `{"do":"interrogate","id":n,"pressure":k}` — давление k задаётся числом, `{"do":"release"|"hand_over"|"execute","id":n}` — исход.
2. Ярлык темперамента — по таблице 01 (bucket_of); база по ярлыку [док 19]: Пугливый 50, Вспыльчивый 20, Бродяга 30, Хладнокровный 10, Упёртый 0, без ярлыка 30. Соответствие ведро → ярлык берётся из 01 [предл: skittish → Пугливый, ordinary → без ярлыка, steady → Упёртый; Хладнокровный и Бродяга — для именных/сценария].
3. Страх допроса = база + k×`step_pressure` (10) + (100 − мораль фракции)×`morale_k` (0.2) [+ Fear именного] [док 19; числа предл].
4. Исход: страх < `talk_threshold` (60) → молчит; иначе по ярлыку: Пугливый, без ярлыка, Бродяга (при оплате) → правда; Вспыльчивый → ложь при страхе < 80, иначе правда; Хладнокровный → ложь-ловушка; Упёртый → молчит, кроме мораль < 20 → правда [док 19; число 80 предл].
5. Эффекты: правда → знание о депо через `_know_set` (reason INTERROGATE_TRUE); ложь → ничего, событие `interrogation_lie`; ловушка → названная площадка получает ловушку, при штурме этого объекта игроком (action assault по объекту) нападающий теряет `trap_losses` (3) бойцов, reason INTERROGATE_TRAP; не более 3 ловушек на мир [док 19]. Один секрет на пленного: повторный допрос того же — ValueError.
6. После допроса: release при страхе ≥ 60 → человек выбывает (`remove_many` с reason RELEASED_DESERTED); release при страхе < 60 → возвращается в ведро, фракция получает шок подозрения `purge_shock` (1) [предл] — запись reason RELEASED_SUSPECT; hand_over → ведро captured фракции-хозяина игрока (если он фракция) или пропадает из учёта с reason CAPTURED; execute → `add_personnel_shock(1.0)` и, если есть свидетели и 02 включён, событие репутации.
7. Параметры в twin/params.py: `interrogation_enabled` False, `talk_threshold` 60, `step_pressure` 10, `morale_k` 0.2, `trap_losses` 3, `max_traps` 3, таблица баз [док 19 / предл].

## 3. Решения Стана и что осталось
Решения [Стан, общее слово 2026-10-27; рекомендации docs/19]: модуль листовой; в мир ничего не пишет сам, а вызывает чужие правила; один секрет; детерминированные исходы; допрос — только пленные уровня B и именные; в CK откладывается до G6.
Допущения [предл]: соответствие ведро → ярлык; порог 80 ложь/правда для Вспыльчивого; ловушка в двойнике — потери при штурме, а не бой; шок подозрения 1; hand_over для игрока без фракции просто выводит человека из учёта. Это двойник; Creation Kit он не описывает.

## 4. Что движок умеет на самом деле (A/B/C)
Двойник: арифметика исходов. Для игры, по docs/19: захват через ЭМ-оглушение — B (поведение ЭМ подтверждено модом Functional Brigs, наш скрипт поверх не проверен); опция активации на оглушённом через IsUnconscious() — C (функция из вики сообщества, под Starfield не проверена); диалог, знание, ростер, шок — A (наши же API). Ловушка (засада) — B. Механизма допроса и сдачи NPC в ванильном Starfield не найдено. Нужно создать: весь механизм допроса.

## 5. Какие моды это уже делали
Проверено 2026-10-27 (поиск и чтение страниц): Functional Brigs (Starfield, Nexus 6330) — оглушённого противника отправляют в карцер корабля и сдают охране, допроса нет; Enhanced Surrender (Starfield) — сдача игрока, не NPC; enRAGE (RDR2, внешний C#) — допрос с правдой, ложью и ловушкой, прототип правил. Готового допроса пленного под Bethesda-игры (Skyrim, Fallout 4, Starfield) в проверенных источниках не найдено (docs/19). Поиск неполон.

## 6. Что не входит
Захват, диалог, реплики, засада в сцене; карцер; пытки как механика; родственные связи; память рядовых о допросе; допрос нескольких пленных одновременно.

## 7. Известные риски
1. Допрос как всезнание: один секрет на пленного и три ловушки на мир; склад переезжает после удара (06).
2. Двойник описывает только арифметику: если захват в CK не заработает (S1 docs/19), модуль остаётся на двойнике и план Б docs/19 (именные через обычный диалог).
3. Сумма людей с пленными — тонкое место закона сохранения; ID7 стоит на всех тиках.
