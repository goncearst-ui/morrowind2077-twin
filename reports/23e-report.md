## Находки
1. Параметры входят в снимок целиком, поэтому любое новое поле Params меняло золотые файлы. По решению Стана (2026-10-28 10:27, «да») из снимка исключены поля Params с `_bug_` в имени (переключатели обратных проверок, 56 штук); при чтении они берут значения по умолчанию. Золотые файлы пересозданы второй раз: в каждом снимке изменилась только строка параметров p; журналы CSV и числа мира те же. Теперь новые переключатели `_bug_` золотые файлы не меняют; новые обычные параметры по-прежнему меняют их (это состояние мира) и требуют разрешения Стана.
2. Замер до правок: подмена `sum` на простой цикл во всей программе не меняла ни одного из 3800 тестов; после замены в коде результат тот же.
