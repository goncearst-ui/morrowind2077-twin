# Отчёт 21a-2: правка 21a по вашим решениям

Дата: 2026-10-27. Spec 21a-2 и plan 21a-2 утверждены вашими ответами на вопросы отчёта 21a (вариант (а) для Дрейфующих, территориальный шок — да, формула морали буквально, смена уклада по умолчанию — да).

## Итог
`python3 -m pytest`: 909 тестов зелёные, 1 красный: EV13, строка «Дрейфующие X6 к тику 500 живы». Это критерий, который я добавил в EV13 по смыслу вашей заботы о Дрейфующих. Он красный честно, причина ниже. Критерий не ослаблял и пометку «известный дефект» не ставил: это решать вам. Остальное зелёное: EV1–EV17 кроме этой строки, обратные R39–R47, EV10, EV11.

## Что сделано
1. Правило 7 для Дрейфующих работает только если у фракции есть объект (`evo_drifter_needs_site`). EV7 переписан: Дрейфующие с объектом при R = 90 уходят в Хранители через 5 тиков, без объекта остаются Дрейфующими 12 тиков (обратная R46 валит EV7).
2. Территориальный шок (`tshock`): +25 обороне за потерянный объект (штурм, сдача актива), затухание 8 в сутки, P = 2.5 × (личный + территориальный). EV16 (потеря объекта в штурме) и EV17 (сдача актива) зелёные, обратная R47 валит EV16.
3. Формула морали при смене уклада осталась буквальной (рост доли поднимает мораль): EV4, EV5 это закрепляют.
4. `evolution_enabled` = True по умолчанию. Прежние 70 сценариев `run()` по умолчанию гонит с выключенной сменой уклада, потому что при включённой краснеют критерии 17 из них: DS4 (штопор), RG1, RG4, RG6, HD1, HD2, IC3, RP1, WS1, WS3, RB1, RB2, RB4, RB5, SW1, SW2 по значениям, WE1 с ошибкой. Эти критерии написаны для неизменного уклада; менять их можете только вы. Журналы 70 прежних сценариев по-прежнему совпадают с эталоном до 21a. Новые сценарии и мир по умолчанию идут со сменой уклада; для прежнего сценария со сменой передаётся `evo=True`.

## Что показал двойник
- Ловушка закрыта: в мире запаса 6 суток при выключенном территориальном шоке Дрейфующие X6 остаются Дрейфующими всё время без единой смены и доживают до конца с 6 людьми (раньше: четыре смены и вымирание на тике 163).
- Но с территориальным шоком они всё равно вымирают. Цепочка: тики 1 и 5 — три штурма, X6 теряет все три объекта; территориальный шок поднимает P до 85 при R = 7, правило 5 делает их Хищниками на тике 4; Хищники без объектов изгоняют людей, чтобы вписать расход в приход (18 изгнанных, 5 дезертиров, 5 погибших), на тике 27 осталось 1 человек, на тике 66 ноль. Мораль при смене Дрейфующие → Хищники выросла на 21 по буквальной формуле (поэтому правило 8 уже не держит их внизу).
- Итого: потеря всех объектов + давление сразу переводят фракцию в Хищников, и хищничество без добычи убивает её быстрее, чем вялая контрабанда в уклад Дрейфующих. Это согласуется с docs/06 («Дрейфующие — переходное, хрупкое состояние»), но противоречит вашей заботе о них.
- В богатом мире (EV12) ничего не изменилось: все шесть фракций живы, Хищники стали Хранителями на тике 6.

## Что решать вам
1. Критерий «X6 жива» в EV13: оставить красным, пока не решим по Хищникам без объектов (рекомендую), либо принять вымирание как норму и убрать критерий (только вы).
2. Хищники без объектов изгоняют людей до нуля. Варианты: (а) Хищники без объектов не изгоняют, а продолжают контрабанду (меняет решения 05); (б) вход в Хищники правилом 5 требует, чтобы у фракции были силы для налёта (armory и численность) — правка docs/07; (в) вес территориального шока в P ниже личного. Моя рекомендация: (б), потому что «ресурсный коллапс → хищничество» в docs/07 предполагает, что есть чем хищничать.
3. Запись в docs/07: условие объекта для правила 7 (вариант (а)) и территориальный шок как вход P (docs/04 уже это описывает); пока правки только в двойнике.
