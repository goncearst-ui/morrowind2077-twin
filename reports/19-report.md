# Отчёт 19: допрос пленного (двойник)

Статус: сделано. Тесты: 3453 зелёных (pytest, 61 с). Эталон tests/baseline_pre19.json снят до правок кода; при interrogation_enabled = False журналы всех сценариев совпадают с ним. Это арифметика двойника; Creation Kit модуль не описывает (захват, диалог, засада в игре — B/C по spec §4, нужно создавать).

## Что сделано
- Флаг interrogation_enabled (по умолчанию False; требует npc_state_enabled). Модуль twin/interrogation.py вызывается из player_action для действий-словарей: capture, interrogate, release, hand_over, execute.
- Новое ведро held (пленные игрока) на фракции, включено в BUCKETS_OUT: общие проверки сохранения людей (в том числе прежние) считают его; пока оно 0, ничего не меняется.
- Страх = база по ярлыку + давление × 10 + (100 − мораль) × 0.2; исходы truth / lie / trap / silent по таблице spec п. 4; знание ставится через _know_set (INTERROGATE_TRUE); ловушка — запись traps и потери нападающего при штурме названной площадки (в assault()).
- ID1–ID11 (twin/x19.py); обратные R130–R135, каждая валит свою проверку.

## Отклонения и допущения (прошу взглянуть)
- Действия допроса принимаются в виде словарей, как в spec, а не кортежей, как прочие действия игрока; поле "by" (фракция игрока) добавлено в capture обязательным: без неё некому поставить знание и засаду. Отказ при выключенном флаге — событие player_failed с кодом DISABLED.
- Ярлык берётся из ведра (skittish → Пугливый, ordinary → без ярлыка, steady → Упёртый); остальные ярлыки (Вспыльчивый, Бродяга, Хладнокровный) задаёт сценарий полем "label" при capture. Бродяга говорит только при "paid": True.
- Названная площадка — склад фракции пленного (если склад в тайнике, ловушки и знания нет, исход молчит). Сработавшая ловушка снимается: потери 3 бойцов нападающего, строка INTERROGATE_TRAP. Лимит 3 ловушек на мир (ValueError на четвёртой) проверен на мире с четырьмя противниками.
- hand_over кладёт человека в ведро captured фракции пленного (чтобы сумма людей по каждой фракции сходилась); «ведро фракции-хозяина игрока» из spec п. 6 я не использовал, потому что приём чужих людей — это отдельный механизм absorbed.
- Fear именного из формулы страха не используется: пленные в этой задаче бакетные.
- Мораль противника в сценариях стоит на месте (evo_m_recover = 0), иначе восстановление морали сдвигает страх на доли очка и меняет исход на границе 60.
- Казнь со свидетелями ставит слух репутации через _rep_kill (02), как убийство именного; без свидетелей слуха нет.
